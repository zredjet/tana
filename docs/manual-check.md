# v0.1 の手動の確認の手順書

v0.1 のすべての操作を、端末ごとに一通り行う手順（filer §12、フェーズ21）。キーを押すのは開発者、仮想マシンの画面の確認は Claude が行う（CLAUDE.md「仮想マシンでの確認」）。

- 起動用のファイルは、起動のたびに試し用のフォルダを作り直す。何度でもやり直せる。
- 左のペインは `work\src`（`work/src`）、右のペインは `work\dst`（`work/dst`）。
- 「［撮影］」の所では、画面をそのまま 3 秒ほど止める（仮想マシンでは、Claude が 2 秒ごとに画面を撮っている）。
- 期待と違ったら、その番号と、起きたことを記録する（全部が期待どおりなら「問題なし」だけでよい）。

## 1. Windows（仮想マシン「Windows 11」）

`%USERPROFILE%\tana-probe\p21` の中のファイルを使う。Windows Terminal（`p21-wt.cmd`）と conhost（`p21-conhost.cmd`）の両方で、同じ手順を行う。

試し用のフォルダ（`p21-sample.ps1` が作る）:

- `work\src`: 写真\（IMG_0001〜0003.jpg）、議事録\、完全削除フォルダ\、abc.txt、run.bat、か゛（NFD）.txt、ごみ箱へ.txt、メモ.txt、報告書.docx、
  大きいファイル.bin（4 GB）、完全削除.txt、読み取り専用.txt、隠しファイル.txt（隠し属性）
- `work\dst`: 写真\IMG_0001.jpg（古い）、報告書.docx（古い）、読み取り専用.txt（古い、読み取り専用）
- `R:\tana-vu5\work-r`（ごみ箱の最大サイズ 1 MB）: small.txt、big2mb.bin（2 MB）

### A. 起動と表示

1. `p21-wt.cmd`（conhost の回は `p21-conhost.cmd`）をダブルクリックする。「Making the sample folders...」の後、2 ペインが出る。［撮影］
2. 窓を小さくする（80 桁×24 行より小さく）。「端末が小さすぎます」が出る。［撮影］ 窓を元の大きさに戻すと、描き直される。
3. `?` でヘルプが出る。［撮影］ 何かキーで閉じる。
4. `v` で Yazi 風の表示になる。`j`・`k` で「メモ.txt」に合わせると、右の列にプレビューが出る。［撮影］
5. `Tab` で表示するペインが [2/2] に変わる。もう一度 `Tab` で [1/2] に戻し、`v` で 2 ペインに戻す。
6. `Ctrl+L` を押す。画面が描き直される（見た目は変わらない）。

### B. 移動・マーク・隠しファイル・開く

7. 「写真」で `Enter` → 中に入る。`Backspace`（または `←`・`h`）で戻ると、カーソルが「写真」にある。`l`（`→`）でも入れる。戻っておく。
8. `.` で「隠しファイル.txt」が出る（暗く表示）。もう一度 `.` で隠れる。
9. `Space` で 2 つマークする（`*` と色）。`a` ですべてマーク、もう一度 `a` ですべて外す。
10. 「メモ.txt」で `Enter` → メモ帳が開く（メッセージ行に「開きました」）。メモ帳は閉じる。
11. 「run.bat」で `Enter` →「実行しますか」が出る。［撮影］ `n` でやめる。
12. `g` → `..\..\..\sample` と打って `Enter` → phase 18 の見本のフォルダに移る。［撮影］
    - 「末尾がドット.txt.」で `Enter` →「この名前のファイルは開けません」。
    - 「か゛き゛（NFD）.txt」などの名前の表示が崩れない（崩れた場合は `Ctrl+L`）。
13. `Ctrl+R` で再読み込み（カーソルの位置は変わらない）。
14. `g` → `..\p21\work\src` → `Enter` で元に戻る。

### C. コピー（衝突・結果）

15. 左で「写真」「報告書.docx」「読み取り専用.txt」をマークし、`y` →「3 項目を覚えました」。
16. `Tab` で右のペインへ移り、`p` → 確認画面（「! 衝突 4 件（トップレベル 3 件）」など）。［撮影］
17. `Enter` → 衝突の画面。［撮影］
18. 「写真/」で `m`（マージ）→ 下に IMG_0001.jpg が出る。`N`（新しいときだけ上書き）→ 新しい方が上書きになる。［撮影］
19. `Enter` → 実行。「読み取り専用.txt」が失敗なら結果の画面が出る。［撮影］ 失敗の理由を記録する。
    - `e` で英語の詳細が下に出る。［撮影］ `e` で閉じ、`Enter` で結果の画面を閉じる。
    - `L` でもう一度出る。`Enter` で閉じる。
20. 右のペインの「報告書.docx」「写真\IMG_0001.jpg」が新しくなっている（プレビューや `Enter` で開いて確かめてよい）。

### D. 進捗と中止・移動

21. `Tab` で左へ。「大きいファイル.bin」で `y` → `Tab` → `p` → `Enter` → 進捗の画面。［撮影］
22. `Esc` → 中止の確認。［撮影］ `y` →「中止しています...」→ 結果の画面（中止しました）。`Enter` で閉じる。
23. もう一度 `p` → `Enter` → 最後まで待つ（数十秒）。「1 項目をコピーしました」。
24. `Tab` で左へ。「議事録」で `y` → `Tab` → `P`（移動）→ `Enter` → 左のペインから消え、右に移る。

### E. ごみ箱・完全削除

25. 左で「ごみ箱へ.txt」→ `d` → 確認画面（合計は出ない）［撮影］→ `Enter` →「1 項目をごみ箱に入れました」。
26. 「完全削除フォルダ」→ `D` → 完全削除の確認（場所・名前・合計）［撮影］→ `Enter` でやめる（消えない）。`n`、`Esc` でもやめる。
27. もう一度 `D` → `y` → 消える。

### F. 名前の変更・新しいフォルダ

28. 「報告書.docx」で `r` → カーソルが `.docx` の前にある。日本語入力で「_最終」を打ち（変換中の文字が入力欄に出る）［撮影］、`Enter` → 名前が変わり、カーソルがその項目にある。
29. 「abc.txt」で `r` → `Home` → `Delete` を 3 回 → `ABC` → `Enter` →「ABC.txt」になる。
30. 「か゛（NFD）.txt」で `r` → 何も変えずに `Enter` → 何も起きない。
31. `n` →「新しいフォルダ」→ `Enter` → できて、カーソルがそこにある。`n` →「写真」→ `Enter` →「同じ名前のものがあります」［撮影］→ `Esc`。

### G. 反対側のペイン・ごみ箱に入らない場所・終了

32. `=` → 右のペインも `work\src` になる。
33. `g` → `R:\tana-vu5\work-r` → `Enter`。
34. 「big2mb.bin」で `d` →「ごみ箱に入らないため実行しません」「D 完全削除の確認へ」［撮影］→ `D` →「次の 1 項目はごみ箱に入れられません。」→ `Esc`。
35. 「small.txt」と「big2mb.bin」をマーク → `d` → `Enter` → 結果の画面（big2mb.bin が失敗、「D 完全削除の確認へ」）［撮影］→ `D` → `y` → 消える。
36. `q` で終わる。端末が元に戻る（プロンプトが出て、打った文字が見える）。［撮影］

### H. VU5（ごみ箱の確認ダイアログ。キーを押した直後）

37. `vu5-key-wt.cmd`（conhost の回は `vu5-key-conhost.cmd`）をダブルクリックする。
38. 「VU5: press any key in THIS window.」と出たら、その窓で何かキーを押す。
39. Windows のダイアログ（「このファイルは大きすぎてごみ箱へ移動できません」）が、端末の前面に出るか、後ろに隠れる（タスクバーで点滅する）かを記録する。［撮影］
40. ダイアログで **「いいえ」** を押す（「はい」は押さない）。窓に `HELPER-RESULT:` の行と、`big.bin` が残っていること（`dir` の結果）が出る。［撮影］ 窓は閉じてよい。

## 4. フェーズ23（UI の骨格の作り直し）で手で行うもの

作り直したもの（filer §4 の「UI の骨格」）:

- キーから操作への解決（keymap）
- キーの案内とヘルプの生成
- 画面ごとの描き方の登録
- 配置の補助
- 見た目の表

自動のテストで確かめたこと:

- キーから操作への対応は、状態ごとの「キーの行列」のゴールデンファイルで、作り直す前と同じことを確かめた。
  - 差は、もともと何もしなかった割り当てを表から除いた分だけ。
  - 端末からの入力の解釈（keys）は変えていない。
- 画面は、ヘルプの 2 枚のほかは、ゴールデンファイルが同じ。

手で確かめるのは、次の 4 つ。

- 新しいヘルプ（キーの欄の形と、76 桁の枠）が、端末で崩れないこと
- 画面ごとのキーが、実際の端末の入力で一通り効くこと
- Esc を速く 2 回押したとき（Alt+Esc として届く）に、確認画面がやめられること
- 貼り付けと日本語入力

| 端末 | 手で行う番号 |
|---|---|
| Windows Terminal | P1〜P8 |
| iTerm2 | P1〜P8 |
| conhost | P1、P3、P6 |
| Terminal.app | P1、P3、P6 |

起動:

- Windows: `%USERPROFILE%\tana-probe\p23` の `p23-wt.cmd`（Windows Terminal）・`p23-conhost.cmd`（conhost）をダブルクリックする。
  試し用のフォルダは 1 章と同じもので、起動のたびに作り直す。
- Mac: Claude の作業用のフォルダの `p23/run-p23.command`（パスは依頼のときに示す）。
  Terminal.app は Finder でダブルクリックし、iTerm2 はパスを実行する。試し用のフォルダは 1 章と同じ形で、2 章の違いに従う。

手順（どれも、期待と違ったら番号と起きたことを記録する）:

- P1: `?` でヘルプが出る。［撮影］
  - キーの欄が「Up k  Down j」「h Left Backspace」の形で、枠が崩れていない。
  - `q` で閉じる。
- P2: 閲覧のキーが効く。
  - 移動: `j`・`k`・`↑`・`↓`・`PgUp`・`PgDn`・`Home`・`End`
  - フォルダの出入り: 「写真」で `l`（`→`）で入り、`h`（`←`・`Backspace`）で戻る。`Enter` で入り、`Backspace` で戻る。
  - そのほか: `Tab`、`Space`、`a`（2 回）、`.`（2 回）、`v`（2 回）、`Ctrl+R`、`Ctrl+L`
- P3: 入力欄のキーと貼り付けが効く。
  - `g` で入力欄を開く。
  - 文字を打ち、`Backspace`・`Delete`・`←`・`→`・`Home`・`End`・`Ctrl+A`・`Ctrl+E` で編集できる。
  - 2 行の文字列を貼り付けると、1 行目だけが入る。
  - `Esc` で閉じる。
  - `r`（「abc.txt」で）で名前を日本語入力で変えて `Enter` を押すと、変わる。
  - `n` で新しいフォルダを作る。
- P4: 確認と衝突の画面のキーが効く。
  - 「写真」と「報告書.docx」を `Space` でマークし、`y` で覚える。`Tab` で右のペインへ移り、`p` を押すと、確認画面が出る。
  - 確認画面で `Enter` を押すと、衝突の画面に進む。
  - 衝突の画面で、次のキーを押す: `j`・`k`・`↑`・`↓`・`PgUp`・`PgDn`・`Home`・`End`、`s`・`o`・`r`・`m`、`S`・`O`・`N`・`R`・`M`、`Space`、`u`（2 回）。
  - `Esc` でやめる。
- P5: 進捗・中止の確認・結果のキーが効く。
  - 「大きいファイル.bin」を覚え、右のペインに `p` で貼り付け、`Enter` で実行する。
  - 進捗の画面で `Esc` を押すと、中止の確認が出る。`n` で続け、`Ctrl+C` でもう一度出し、`y` で中止する。
  - 結果の画面で、次のキーを押す: `↑`・`↓`、`Space`、`e`（2 回）。
  - `Enter` で閉じる。
  - `L` で結果をもう一度出し、`Esc` で閉じる。
- P6: Esc を速く 2 回押すと、確認画面をやめられる。
  - P4 と同じく `p` で確認画面を出し、`Esc` を素早く 2 回押す。
  - 確認画面が閉じる（閲覧に戻る）。
- P7: ごみ箱と完全削除のキーが効く。
  - 「ごみ箱へ.txt」で `d` を押し、確認画面で `Enter` を押すと、ごみ箱に入る。
  - 「完全削除.txt」で `D` を押し、完全削除の確認で `Enter` を押すと、やめる（消えない）。
  - もう一度 `D` を押し、`y` で消える。
- P8: `q` で終わる。端末が元に戻る（プロンプトが普通に使える）。
